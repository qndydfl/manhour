홈 화면 바다 배경 영상 사용 방법

권장 방법
- 관리자 페이지의 Background images에서 key를 index_ocean_background로 등록합니다.
- Image file 또는 Video file 중 하나를 업로드합니다.
- 업로드 파일이 없으면 CSS 바다 배경이 기본으로 표시됩니다.

static 파일로 직접 관리하려는 경우에만 이 폴더를 사용할 수 있습니다.

권장 형식
- MP4 (H.264)
- 1920x1080 또는 1280x720
- 10~30초의 자연스럽게 반복되는 영상
- 소리 없는 영상
- 가능하면 8MB 이하

파일이 없거나 재생할 수 없는 환경에서는 CSS 물결·물고기 배경이 자동으로 표시됩니다.
